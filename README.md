# ARS 原创宇宙星图

一个浏览器端 Three.js 星域图谱，展示 ARS01–ARS10 目前主设定中的原创恒星、行星、故乡遗址、关联企划与已知地点。星域位置仅供故事导航，不代表现实天文距离或现实天体数据。

## 内容

- 地球：ARS01、ARS05、ARS07、ARS08、ARS09、ARS10 的主要舞台；也是 ARS02 爱丽丝与 ARS06 苏芮雅的来源。ARS06 主舞台为缇兰诺，不能将角色出身与作品主舞台混为一谈。
- 太阳系：水星、金星、地球、火星、木星、土星、天王星、海王星八大行星均可聚焦；露菲茵星遗址不属于太阳系。
- 露米菈星、缇兰诺星、芙蒂丝星球：各作明确的文明舞台；赛拉菲斯星是 ARS08 的故乡，迦罗厄星是 ARS09 的制造来源，二者不再冒充地球主舞台。
- 维斯卡尔星：气候寒冷、冰雪广布的科技星球，领袖为诺佩拉。高纬度与高山长期覆雪，低纬度仍有未长期封冻的海域与河谷，城市和农业区集中于较温暖地带。诺佩拉、莉薇娅、彩绪凛和米欧来自这里；星球与圣都位于同一曦源星系的不同轨道，存在纷争，具体登场与角色职责仍以各作企划为准。
- 露菲茵星和蒂娅星：分别位于靠近地球的独立恒星系。露菲茵的家园遭侵略毁坏，但有幸存者，文档未确认整颗行星碎裂；蒂娅明确已毁灭。两者均收录于遗址分类，只有蒂娅显示破碎标记。
- 莱勒星、诺克顿星、卡奇星、杜莫恩星：根据 ARS01、ARS07 的外域角色标记的远距族源世界。主设定未给出母星社会细节，星图不据个别角色推定整颗星球的立场。
- 诺克提亚星、璐赛特星：分别按 ARS03 伊瑟拉、ARS10 梦璃娅的出身补录的远距族源世界；星名由作者补充命名，DOCX 原文未具名。
- 米尔珐星残骸：ARS04 绯陌的故乡，被吞噬巨兽伽诺姆吞掉，收录于遗址分类并显示破碎标记；星名由作者补充命名。
- 砾烬星、霜辉星、青幕巨行星：静渊星系的岩质、冰质与气态无人天体，不承担主线舞台。
- 太阳及露辉、露茵、蒂蓝、曦源、弦曦、翡曜、芙曜、赛辉、迦穹、晦曜、雾环、赤衡、黛穹、静渊、暗曜、蚀曜、璐曦：十八个导航节点，目录中均可聚焦。芙蒂丝、赛拉菲斯、迦罗厄、露菲茵、蒂娅、米尔珐分别属于独立恒星系；圣都与维斯卡尔共同位于曦源星系，叙事航路只表示作品之间可通行，不表示所有世界共享恒星。
- 距离计算：可选择任意两个世界，按企划星图坐标与当前演示位置计算距离、光速通信时间，并结合世界关系、跨恒星尺度与现实航天能力给出直接判断。
- 聚焦和总览视图、拖拽旋转、滚轮缩放、恒星与星球搜索、点选查看设定。
- 总览按星图演示光年坐标等比例定位；全域尺度把 0–80 光年范围收为可点开的“已知近域”，展开后各节点仍处于原坐标。

剧情事实以 `D:\原创游戏企划` 下 ARS01 至 ARS10 各作当前主 DOCX 为准；角色图集与作者明确补充提供维斯卡尔等尚未写入主线的设定。恒星名称、坐标、轨道参数及无人天体主要服务星图演示，不代表各作已写入剧情。对应关系记录于 `CANON_AUDIT.md`。原 AI 动画 HTML 未同步修改，制作新镜头时应先对照主设定。

太阳系内的距离采用计算时刻的三维日心星历，以万公里或亿公里展示；原创世界之间以及太阳系与原创世界之间的距离使用本企划专用星图导航坐标，模型值不是现实天文测量。35 个世界可形成 595 组不同配对，太阳系 28 组另有逐对的探测史与任务约束说明，其余组合结合双方的具体环境与已知剧情关系判断。现实技术判定不采用魔法、跃迁或超光速航路；帕克太阳探测器每秒约 192 公里的近太阳瞬时峰值只用于极度乐观的时间下限，不能视为可持续巡航速度。

## 时间与轨道口径

太阳系八大行星的位置与轨道线由内置的 Astronomy Engine 2.1.19 `HelioVector` 按当前 UTC 时刻求得，保留相对于 J2000 黄道面的轨道倾角与摄动，距离取两颗行星三维日心向量之差。轨道线在当前时刻起的一个公转周期内采样，属于可视化近似；行星位置与距离不由轨道线插值。球面自转仍使用各行星设定的恒星日与轴倾角，金星与天王星按逆行自转处理；土星和天王星的环随自转轴倾斜。星历库采用 MIT 许可，版权声明保留于 `vendor/astronomy.js`。行星贴图与统一展示半径不代表实际比例。

原创恒星系使用各自的设定恒星质量和开普勒第三定律计算公转周期，每个世界另有设定自转周期与轴倾角；这些数字是企划演示值，不冒充真实观测。圣都与维斯卡尔分别位于曦源星系的内外轨道，露菲茵与蒂娅分别位于近地的独立恒星系。远航、古道等叙事导航分组的展示轨道不代表其中世界共享同一物理恒星。为保证星图可点选，行星球体半径采用统一展示尺寸，不代表真实体积比例。

## 原创贴图

`textures/original/` 中的行星 PNG 由 `scripts/generate-original-textures.py` 使用可复现噪声、地貌阈值和手工配色生成。没有导入 NASA、现实星球照片或原项目的太阳系贴图。可以指定名称，只生成新增纹理而不覆盖现有文件：

```powershell
python scripts/generate-original-textures.py kachi dumoen
```

脚本依赖 NumPy 和 Pillow。浏览星图只需静态文件服务，不依赖 Python 图像库。

## 运行

双击 `启动.bat`，或在项目目录执行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8765/`。页面通过 CDN 加载 Three.js 和 Lucide，需要联网。ES Module 不能直接以 `file://` 打开。

## 操作

拖拽旋转，滚轮缩放，右键拖拽平移；在目录中点选星球，或直接点击 3D 行星。移动端使用右上角目录按钮切换世界。

总览中向内缩放时，滚轮与双指缩放朝向指针或双指中心附近的恒星，放大按钮朝向画面中心附近的恒星；接近后自动进入恒星聚焦，避免镜头停在星域中心的空白区域。向外缩放可返回总览，重置按钮恢复当前视图的初始取景。
